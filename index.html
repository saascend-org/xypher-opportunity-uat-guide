The sandbox

xypher--saascendfc.sandbox.my.salesforce.com

If you can skip a stage, stop

You should not be able to move a deal without filling anything in. If you can, your login has an override it should not have — tell us, because nothing you test after that proves anything.

Two other things: no emails are sent from a sandbox, so all system guidance appears as Chatter posts on the record; and it holds real customer data, so treat it as live.

What we want back

  1. Are the gates set at the right height? Too strict is as bad as too loose.
  2. Is a plain renewal too easy to push through? It is meant to be light. Is it too light?
  3. The ownership question on the renewals page — that one changes which entity books revenue.
  4. Anything you expected to find and could not.

Post feedback in Chatter on the record it concerns, so we see it in context. Anything broader, send it to Tej.
