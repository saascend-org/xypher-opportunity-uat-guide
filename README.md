# Xypher Deal Desk — Opportunity UAT guide

Sales-team UAT guide for the Xypher Salesforce build: creating an opportunity, what each stage gate
requires, contact roles, auto-renewal, and a step-by-step method for rebuilding open pipeline from Zoho
by hand.

Published for the Xypher sales team by SaaScend.

## Data safety

The sandbox this documents is a **full copy containing real Xypher customer data**. Every screenshot in
this repository was captured from `[DEMO]` records only, and the capture script aborts if a known real
customer name appears on screen. No real customer name, contact or deal value is published here.
